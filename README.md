A: รองรับ Windows 10 และ Windows 11 ทั้งแบบ 32 บิตและ 64 บิต อย่างเต็มรูปแบบ

**Q: ฉันสามารถกู้คืนไฟล์จาก USB drive ได้หรือไม่?**
A: ได้ รองรับการกู้คืนจาก USB drive, การ์ดความจำ, และอุปกรณ์จัดเก็บข้อมูลภายนอกอื่นๆ ได้หลากหลาย

A: หลังการติดตั้ง โปรแกรมจะอยู่ในเวอร์ชันทดลอง คุณสามารถป้อนรหัส许可เพื่อเปิดใช้งานเวอร์ชันเต็มได้ทันทีผ่านเมนู激活
